# 🛍️ E-commerce Website

A responsive e-commerce website created as a frontend development project. The website provides a clean and user-friendly interface for browsing products and interacting with different sections.

## 🚀 Features

* Responsive e-commerce interface
* Product showcase
* Registration form
* Feedback form
* Attractive and organized layout
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
